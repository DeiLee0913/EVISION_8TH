# EVISION_8TH

이 레포지토리는 EVISION 8기 동아리 활동에서 나온 산출물들을 정리하고 공유하기 위해 만들어졌습니다.  
스터디, 프로젝트, 과제 등의 결과물을 기록하고 관리합니다.

## 📌 목적
- 동아리 활동 산출물 아카이빙
- 학습 및 프로젝트 과정 공유
- 팀원 간 협업 및 기록 관리

## 📂 구성
- `week1`  1주차 활동 결과물
- `week2`  2주차 활동 결과물
- `...`
